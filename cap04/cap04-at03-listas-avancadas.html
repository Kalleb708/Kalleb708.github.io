2. Ranking de Tecnologias

  1. GitHub

    O GitHub é a maior plataforma de hospedagem de código-fonte e projetos do mundo, utilizando o sistema Git para controle de versão.

  2. Git

    Git é um sistema de controle de versão distribuído, gratuito e de código aberto, utilizado para rastrear alterações em arquivos de código-fonte durante o desenvolvimento de software.

  3. JavaScript

    JavaScript (JS) é uma linguagem de programação interpretada, de alto nível e multiparadigma, fundamental para o desenvolvimento web.

  4. CSS

    CSS é uma linguagem de estilo fundamental utilizada para definir a apresentação visual de documentos HTML.

  5. HTML

    HTML é a linguagem de marcação padrão para criar a estrutura de páginas web.

3. Glossário Técnico

HTML
linguagem de marcação padrão para criar a estrutura de páginas web.
CSS
linguagem de estilo fundamental utilizada para definir a apresentação visual de documentos HTML.
JavaScript
linguagem de programação interpretada, de alto nível e multiparadigma, fundamental para o desenvolvimento web.
DOM
uma interface que representa páginas HTML/XML como uma árvore de objetos para manipulação por scripts.
API
é um conjunto de regras e protocolos que permite que dois softwares conversem entre si.
HTTP
é o conjunto de regras fundamental para a troca de dados na World Wide Web (WWW).
URL
É o endereço exclusivo e padronizado utilizado para localizar recursos na internet, como páginas web, imagens ou arquivos.
DNS
(Domain Name System - Sistema de Nomes de Domínio) é a "agenda telefônica da internet", responsável por traduzir nomes de domínio fáceis de lembrar (como www.google.com) em endereços IP numéricos (como 192.0.2.1) que os computadores usam para se localizar e carregar recursos na rede.
